# Autolavado La Avenida

Sitio web en React con Vite. Una sola página, adaptable a escritorio y móvil.

## Carpetas

- `src/components/layout` — encabezado, pie y contenedor de la página
- `src/components/sections` — inicio, servicios, precios, galería y contacto
- `src/components/ui` — piezas reutilizables (botones, tarjetas)
- `src/data` — datos del negocio y listado de precios
- `src/assets/images/logo` — logo
- `src/assets/images/gallery` — fotos
- `src/styles` — estilos globales
- `public` — favicon y archivos estáticos

## Desarrollo

Requiere Node 18 o superior.

```bash
npm install
npm run dev
```
